# Issue-tracker

## Live Demo
[https://issue-tracker-phi-three.vercel.app/](https://issue-tracker-phi-three.vercel.app/)

A simple web-based Issue Tracker application to help teams manage and track issues efficiently.

## Features
- Create, view, and manage issues
- User authentication (sign up, log in)
- Dashboard for issue overview
- Responsive UI

## Technologies Used
- Next.js
- React
- TypeScript
- Supabase (for backend/database)
- Tailwind CSS

## Installation
1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd Issue-tracker
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up environment variables (see `.env.example` if available).
4. Run the development server:
   ```bash
   npm run dev
   ```

## Usage
- Access the app at `http://localhost:3000` after starting the development server.
- Sign up for a new account or log in.
- Create, view, and manage issues from the dashboard.
